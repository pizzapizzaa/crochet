ZippyZack importer

Where your shop lives, and the secret that lets this extension write to it.

The site your POS runs on. Just the address — no /pos on the end.

Set POS_IMPORT_TOKEN in your shop's environment to a long random string, and paste the same value here. It is what tells your shop this extension is yours; anyone who has it can write products into your catalogue.

What an import should default to

A markup sets what you sell for and keeps the shop's own price as your cost. Leave it at 0 to import the price as-is.

Off by default: an import arrives with somebody else's description and wants rewriting before customers see it.
